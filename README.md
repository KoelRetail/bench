# Staging bench — KOEL Retail

Interactive 3D reference for the Palo Alto Prisma SDWAN edge site standard
as it is staged on our benches: two ION 1200-S routers under two stacked
Cisco C9200 switches, POLR 5G on the switch, six workstations and six
registers per bench.

Drag to orbit, scroll to zoom, use the filters to isolate a cable group,
or switch to walk mode. Click a device to open its manual.

Static site — no build step, no server.
