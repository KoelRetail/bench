# Staging Bench Stores — KOEL Retail

Interactive 3D reference for how a store staging bench is built and cabled:
two ION 1200-S edge routers under two stacked Cisco C9200 switches, POLR 5G
on the switch, six workstations and six registers per bench.

Drag to orbit, scroll to zoom, use the filters to isolate a cable group, or
switch to walk mode. Click a device to open its manual.

Static site — no build step, no server.
